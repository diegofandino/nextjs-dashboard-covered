# nextjs-dashboard-covered
This is a interactive dashboard in Next.JS 16 (App Router) with tailwindcss, postgresql and docker.

## Features
- Dashboard page
- Invoices page
- Customers page

## Technologies
- Next.JS 16 (App Router)
- Tailwind CSS v3.4
- PostgreSQL v14.3
- Docker

## Run the project
1. Clone the project.
2. Copy `.env.example` to `.env` add your credentials.
3. Run `docker compose up -d`
4. Run `pnpm i`
5. Run `pnpm run dev`
